# Jeethu G Portfolio V3 — Natural + Interactive

This is the natural futuristic version:
- Intro / Enter Experience screen
- Working navigation and mobile menu
- Smooth scrolling and active section highlighting
- Working Resume download
- Working LinkedIn / GitHub / Credly / email / project links
- Interactive Skills tabs
- Interactive Research cards
- Scroll progress
- Reveal animations
- Subtle Three.js atmospheric 3D background
- Natural forest / mountain / water / sunlight visual language

Run in the portfolio folder:
`py -m http.server 8000`
Then open `http://localhost:8000`.

The site is self-contained in index.html plus the assets folder, so there is no separate build step.
